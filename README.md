# 📊 Waze User Churn Prediction (Google Advanced Data Analytics Project)

## 🔍 Project Overview
This project analyzes user behavior data from the Waze app and builds a machine learning model to predict **user churn**.

It follows the **PACE framework**:
- Plan
- Analyze
- Construct
- Execute

---

## 🎯 Business Problem
User churn is a critical challenge for digital platforms. This project aims to:

- Identify key factors influencing churn  
- Build a predictive model  
- Provide actionable insights  

---

## 📁 Dataset
- 1 dataset with 13 features  
- Includes user activity, sessions, and behavior metrics  
- Cleaned and prepared for analysis  

---

## ⚙️ Tech Stack
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- XGBoost  
- Jupyter Notebook  

---

## 🔬 Project Workflow

### 1. Plan
- Defined business objective  
- Identified churn variable  

### 2. Analyze (EDA)
- Univariate & Bivariate analysis  
- Data visualization  
- Outlier detection  

### 3. Construct (Modeling)
- Feature engineering  
- Logistic Regression  
- Random Forest  
- XGBoost  

### 4. Execute (Evaluation)
- Accuracy, Precision, Recall, F1-score  
- Model comparison  

---

## 📈 Key Insights
- Low activity users are more likely to churn  
- Engagement is a strong predictor  
- Behavioral features drive model performance
